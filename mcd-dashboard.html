The MCD is a standard set of loan data fields and delivery file format that mortgage lenders and independent mortgage banks provide to regulators for the loan-level review portion of regulatory compliance examinations. It’s designed to replace the Loan Examination File (LEF). Lenders and regulators can test a single loan or an entire portfolio against the MCD: lenders to cure defects before an exam, regulators to run risk-based reviews.

Brought by
MISMO, in partnership with the Conference of State Bank Supervisors (CSBS), to replace the inconsistent Loan Examination File (LEF) format with a standardized compliance dataset lenders and regulators could test loans against consistently.
Date started
July 2022

Why MISMO is working on this

1
Manual, inconsistent reviews slow examinations down.
Regulators examine individual loans against consumer-protection rules (disclosures, ability-to-repay, points and fees, high-cost mortgages, and more) largely by hand, without a standard format to run technology against.
2
Inconsistent formats break compliance technology.
For automated review to work across the industry, data submissions need one common structure, fields, names and enumerations: a shared language for regulators, lenders and vendors.
3
Lenders want to catch issues before the exam.
The same standard that lets regulators run risk-based reviews lets lenders test their own portfolios and cure defects ahead of time.
